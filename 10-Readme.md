# JavaScript Self-Study Assignment

## Topics Covered
1. Introduction to JavaScript
2. Variables and Data Types
3. Operators and Conditional Statements
4. Loops
5. Functions
6. Strings
7. Arrays
8. Objects

## Mini Project
Student Marks Manager

The project accepts student names and marks, displays
pass/fail results, calculates the average, and identifies
the student with the highest marks.

## Requirements
- Node.js installed

## How to Run
Run each program using:

node "File Name" Example - "node 01-introduction.js"

Run the mini project using:

"node mini-project.js"
